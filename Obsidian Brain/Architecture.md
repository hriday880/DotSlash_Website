# Platform Architecture

The DotSlash website is a purely modern, serverless-edge hybrid.

## Components
1. **Frontend:** [[Frontend_Stack]] built for speed and aesthetics.
2. **Backend/Database:** [[Database_Schema]] running on the edge using Turso (SQLite).
3. **Security:** Custom [[Role_Based_Access]] implemented in the [[Admin_Portal]].

We strictly adhere to the [[Cyberpunk_Aesthetic]] across all layers.
