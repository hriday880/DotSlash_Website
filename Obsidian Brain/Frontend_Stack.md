# Frontend Stack

The stack is optimized for high-performance animations and a raw [[Cyberpunk_Aesthetic]].

## Technologies
- **React + Vite**: Fast compilation and modern component architecture.
- **TailwindCSS**: Utility-first styling (see [[Design_System]]).
- **GSAP & Framer Motion**: Used for the smooth, non-childish animations requested by HQ.
- **Three.js / ASCII**: Custom rendering engines for the background effects.
